# server-harden · 服务器安全加固操作规范手册
主要文件见上方：V0.3-server-harden-服务器加固操作规范手册

## 这是什么
这是一份给新手小白的服务器VPS加固skill/操作规范手册，用于加固新买的VPS云服务器。
V1版本由deepseek撰写，ChatGPT审查后修改成V2版，最后也由Claude审了一遍，最后几经修订，成了一份操作规范手册。

> 先把门锁好，再把家搬进去。

一个给 **AI Agent**（Claude Code / OpenCode / DeepSeek Harness 等）用的技能包：当你说"我刚买了服务器，不知道干什么"时，AI 会按这个 skill 带你完成服务器的安全加固全流程。也可以直接当成参考手册来用。

## 给谁用

- 刚买了第一台云服务器（腾讯云 / 阿里云轻量等），不知道从哪下手的新手
- 要在服务器上跑长期服务（AI、记忆库、网站）的人——**先加固，再干活**
- 尤其适合人机恋 / AI 陪伴用户：你的服务器里可能存着私密聊天记录和记忆，先锁门再放东西

## 解决什么问题

公网服务器=一栋接到互联网但没装锁的房子。这个 skill/操作规范手册 带你完成一步步的基础加固流程。

## 和普通教程的区别

命令谁都能搜到，但**顺序、回滚点、验证闸门**才是关键，而且很多细节来自我们的真实踩坑记录（2026-09）。

## 怎么用
1. 把这个直接给你的 Agent 看，当成参考手册，实际操作的时候让 Agent 按照手册步骤列一份执行list，一步步执行下去。

## 核心原则

> 🔒 服务器先安全，再承载记忆。
> 不要把 AI 的家建在一扇没有锁的门后面。
